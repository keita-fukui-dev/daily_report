## 取り組んだ課題一覧
- Claude Codeで作成したJavaScriptのToDoアプリ課題(100行強)で関数間の処理の流れを追跡したり、理解を深めたりした
- Git・GitHubの勉強会に参加した(add・commit・push、merge、conflict解消)

## わかったこと
- ToDoアプリの処理を最初から最後まで一通り追えるようになった
- Chrome DevToolsのデバッグショートカット(Mac)を理解した
  - step into: Command + ;
  - step over: Command + '
  - step out: Command + Shift + ;
  - 内部コードに誤って入った場合もCommand + Shift + ;で脱出できる
- クロージャーの仕組みを「関数のネスト構造の時に、変数が保持される」みたいなざっくりした感じで理解した。
- 関数には即実行されるものだけでなく、初回は登録だけして、その登録したイベントが発生した時点で指定した無名関数を実行させるものがあると知った。（addEventListenerのこと）←setTimeoutと同類の非同期処理
- 無名関数を引数として正しく指定しないとエラーが発生することが分かった(詳細な理由は未理解)
- constは定数だが実は変数の一種であり、オブジェクトのプロパティは変更できても再代入はできないと理解した
- Gitの一連の流れとマージの違いを理解した
  - git add . → commit → pushの基本フローを学んだ
  - squash merge・rebase merge・通常マージの違いとconflict解消方法を教わった
- ターミナルのプロンプト表示を講師の設定を参考にカスタマイズし、短縮できた(画面分割操作のため有用)
