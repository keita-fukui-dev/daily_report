## わかったこと
- バイブコーディングについては、学んでからやるよりかは、実際にやってみてから何を知るべきか特定して、知らないことを学ぶという順番の方がおすすめ。
- バイブコーディングの幅を広げるために、MCP などを使って外部と接続させたり、例えば IDE の VS Code と接続させたりすることで、できることが大きく広がる。
さらに Git / GitHub やデータベースを扱えたり、デプロイやセキュリティのこともカバーできたりすると、非常に多様なことができるようになる
- AIの回答は確率で変わるので、同じプロンプトを並列で投げてうまくいくものを採用するっていうやり方もある。
- うまくいかなくなったり、動かなくなったりしたら、前のバージョンに戻してもう一度同じプロンプトを投げてみる、という方法もある。
- LLMを理解することで、応用が効くようになるし、失敗にも対処できるようになる。
- LLM がやっていることの本質は、次に来る言葉を予測すること。
- LLM が知識を持っているのではなく、統計的なパターンを学んでいるといった方が正確。
- そのため、学習データにないパターンや少ないパターンにおいては、解答精度が落ちることがある。
- プロンプトとは予測の出発点である。そのため、明確な出発点であれば予測の選択肢が絞られ、曖昧な出発点であれば予測の選択肢が散らばり、回答が安定しなくなる。
- リモートリポジトリからクローンして、ローカル上でブランチを切って、ブランチ上で編集をして、git add、git commit、そして git push をしてプルリクエストを送るまでの流れを学んだ
- コンフリクトを起こしたときに、GitHub 上ではなく Git 上で対応する方法を学んだ
- リベースでのマージのやり方を学んだ。
- 間違ってリベースした際は git rebase --abort を使う
- 混乱して理解できないこともあったが、練習を重ねることで習得できるだろう。一通りの流れを理解しながら進められた点は有意義であった。
- JavaScript はオブジェクト指向。この理解が非常に重要。
- ウェブページ表示時に生成される仮想DOMはオブジェクトとして扱えるが、階層が深くなると構造の把握が困難となる。Reactは、この複雑な階層構造を分かりやすく解消する技術である。
- 後ろにメソッドを持ってこれるのはオブジェクト型。

## 感じたこと
- 就寝時間が遅くなると日中に強い眠気を感じることが多い。就寝時刻の調整は困難であるため、眠気を感じた際は短時間の仮眠をとるようにしたい。
- 昨日よりも3時間も学習時間を増やすことができたが、最低目標時間の8時間には到達していない。しっかり仕組みを利用して、勉強時間を確保していきたいと思う。
- SlackのTimesにて、ボイスメッセージで目標を宣言した。口に出した以上は達成しなければならないという心理が働き、何としてもやり遂げようとする強い力が湧いている。実際に、これまで以上に体が動くのを実感しており、宣言して本当に良かったと感じている。使える仕組みはすべて活用し、何が何でもロードマップを完走して目標を達成したい。
- Typelessは昨日の時点で、何回も長文を喋ったにもかかわらず録音できていなかったり、文字起こしができなかったりすることがあった。Ryoさんに相談したら最長でも1分程度にしておくと良いとのこと。今日も Typeless ゴリゴリ使ったけど、1分以内だったら全然問題なかったので、これを継続していく。
