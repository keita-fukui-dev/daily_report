## わかったこと
- 制御コンポーネントは入力値を React のステートに保持し、value で再表示する。入力中のバリデーションや検索窓のリアルタイム絞り込みに必須だと理解した
- ネストしたオブジェクトや配列は、スプレッド構文1回ではシャローコピーとなり内部が参照のままになる。map とスプレッド構文を組み合わせて新しいオブジェクトを作る
- フォームの onSubmit では、画面リロードを防ぐためハンドラー冒頭で e.preventDefault() を呼ぶ
- ハンドラーにおいて、イベントの型は自由に命名できず（型呼び出しのため）、仮引数名（e、event など）は自由に決められる
- useEffect は再レンダリング後に実行される。依存配列の値が前回から変化した場合のみ内部の処理が実行され、再レンダリング自体は抑制しない
  - 第二引数に空配列 [] を指定した場合は初回レンダリング後に1回だけ実行される
  - 第2引数を省略すると、レンダリングのたびに実行される
- 副作用とは外部とのデータのやり取りや非同期処理（setTimeout、API 取得など）を指す。useEffect 外で API を呼ぶと「取得→state 更新→再レンダリング→再取得」の無限ループになる
- Axios は axios.get("URL") で Promise を返す。fulfilled なら .then()、rejected なら .catch() で処理できる
- HTML を JSX/TSX に移す際は、for → htmlFor、class → className のように属性名を修正する
- thead・th・tbody を使うとセマンティックになり、クローラーが理解しやすく SEO にも有利になる
- カスタムフックは hooks ディレクトリに TS ファイルとして置き、コンポーネントのロジックを切り出す。疎結合になり、ロジックを使い回せてコンポーネントも見やすくなる
- ghq で repo コマンドを使うと、クローン済みリポジトリを探しやすくなる
