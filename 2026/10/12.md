## わかったこと
- 空文字で保存した際に無反応だと利用者が不安になるため、赤文字で「文字を入力してください」と表示する形に修正した
- 空文字で問題ない箇所のuseState初期値設定は不要なので削除した
- `npm run dev`の実行内容は設定次第で変わる。過去リポジトリの設定ファイルで確認できた
- Vercelへのデプロイは Claude Code からはできず、手動で行った
- バンドル処理でコンポーネント名が1文字に省略され、デプロイ後のページではDevToolsでのトレースが困難になる
- コードのトレースは、`npm run dev`でローカル起動したページのDevToolsで行うのが良い
